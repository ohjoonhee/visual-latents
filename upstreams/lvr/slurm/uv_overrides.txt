# uv override for two unresolvable/unbuildable pins in the (otherwise pristine)
# upstream requirements.txt — applied via `uv pip install --override` so
# requirements.txt stays byte-identical to upstream (faithfulness).
#
#  - av (PyAV): the frozen av==14.3.0 was YANKED from PyPI, and the whole av 14.x
#    line ships NO binary wheels (sdist only) — uv would compile it from source,
#    which needs system FFmpeg dev libs (libavformat/codec/...) absent on the
#    compute node, so the build fails. av 17.0.1 ships cp311 manylinux wheels and
#    is exactly what the proven local eval venv runs. av is video-decode (PyAV),
#    off the LVR image path, so the version is functionally irrelevant — we only
#    need it to install from a wheel.
#  - huggingface-hub==0.30.2 contradicts transformers==4.54.0 (needs hub>=0.34);
#    a stale line in the upstream freeze. Bumping restores consistency
#    (transformers pulls hub 0.36.x).
#
# Validated: `uv pip install av==17.0.1` installs from a wheel (no FFmpeg), and
# `uv pip install --dry-run -r requirements.txt --override <this> boto3` resolves
# the full set with torch 2.6.0 / transformers 4.54.0 / deepspeed 0.16.7 / trl
# 0.17.0 intact.
av==17.0.1
huggingface-hub>=0.34.0,<1.0
