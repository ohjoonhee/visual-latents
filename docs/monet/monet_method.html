The surrogate loss isolates alignment gradient to the latent-generation graph

Paper Eq. 9 — what's optimized

$$\mathcal{L}'_{\text{align-obs}} = \frac{1}{N}\sum_i \text{stop\_grad}\!\bigg(\frac{\partial \mathcal{L}_{\text{align-obs}}}{\partial \hat h^{(i,L)}_{\text{latent}}}\bigg)^{\!\top}\; \hat h^{(i,L)}_{\text{latent}}$$

Eq. 10 — resulting flow

$$\frac{\partial \mathcal{L}'_{\text{align-obs}}}{\partial \theta} = \bigg(\frac{\partial \mathcal{L}_{\text{align-obs}}}{\partial \hat h^{(i,L)}_{\text{latent}}}\bigg)\;\bigg(\frac{\partial \hat h^{(i,L)}_{\text{latent}}}{\partial \theta}\bigg)$$

"Gradients flow only through the generated latent embeddings to the model parameters."

Code (src/trainer.py:11-42, verbatim)

def compute_latents_only_loss(latents, loss_for_latents):
    ce_vec_list = _flatten_tensors(latents)
    grads = torch.autograd.grad(
        outputs=loss_for_latents,
        inputs=ce_vec_list,
        retain_graph=True,
        create_graph=False,
        allow_unused=True,
    )
    safe_grads = [g.detach() if g is not None
                  else torch.zeros_like(v)
                  for v, g in zip(ce_vec_list, grads)]
    proxy_loss = torch.stack(
        [(v * g).sum() for v, g in zip(ce_vec_list, safe_grads)]
    ).sum()
    return proxy_loss

Footgun: allow_unused=True silently returns None → zero grad → silent no-op if ce_patch_vec isn't in the CE-forward graph. Hence our smoke gate [devfix-check] latent_only_connected=True.

Without the surrogate

Alignment gradient flows through the entire LM trunk + the latent graph. The trunk is CE-trained; the alignment signal pushes it to compensate for latent miss. Latents stay underdetermined → collapse.

With the surrogate

Alignment gradient flows only via θ → ĥlatent → … → Lalign. Latents are forced to carry the per-layer information of obs tokens.

Cosine distance summed over all transformer layers — deviation from prior latent-CoT work

Paper Eq. 1

$$\mathcal{L}_{\text{align-obs}} = \frac{1}{N}\sum_i \sum_l \big[1 - \cos\big(\text{stop\_grad}(h^{*\,(i,l)}_{\text{obs}}),\; \hat h^{(i,l)}_{\text{obs}}\big)\big]$$
  • Teacher: same prompt with aux images. Stage-1 SFT ckpt as teacher.
  • Student: aux images replaced by K latent slots.
  • Sum over observation-token positions × all layers.
  • .detach() on teacher.

Code (modeling_qwen2_5_vl_monet.py:244-250)

def alignment_loss(teacher, student):
    if teacher.dim() == 3:    # [L_layers, N_align, H]
        return (1 - F.cosine_similarity(
            teacher.to(student.device), student
        )).mean()
    elif teacher.dim() == 1:  # last-layer fallback
        return 1 - F.cosine_similarity(student, teacher, 0)

Paper: "Unlike previous latent-visual reasoning work, which aligns only the final-layer representations, we align all layers."

Aux images are visible only to latent embeddings, never to subsequent text

   question image ───────────────► everyone (default)

   aux_image_i ─────────► latent_block_i (4D mask: allowed)
                          │
                          └─► obs_tokens_i (allowed)
                                │
                                └─► downstream text (allowed)

   aux_image_i ──✗── obs_tokens   ──✗── downstream text
                          (blocked by 4D mask)
  • Default Monet flags: latent_can_see_all_previous=True, observation flags off. So latents see aux images + prior latents; obs/text don't see aux images.
  • Forces the information path: aux_image → latent → obs/text. Latents become the bottleneck.
  • Code: src/utils.py::build_4d_attn with ten boolean flags + find_segments_1d.
  • Mask is dict-form {"full_attention": [B,1,L,L]}; if passed as bare tensor, the model creates a standard causal mask (silent fallback).

Stage 3: student inputs strip assistant-turn aux images; supervise against Stage-2 teacher latents

$$\mathcal{L}_{\text{stage3}} = \mathcal{L}_{\text{NTP}} + \beta \cdot \mathcal{L}_{\text{align-latent}}, \quad \beta = 2.0$$
$$\mathcal{L}_{\text{align-latent}} = \frac{1}{N}\sum_i \sum_l \big[1 - \cos\big(\text{stop\_grad}(h^{*\,(i,l)}_{\text{latent}}),\; \hat h^{(i,l)}_{\text{latent}}\big)\big]$$
  • Same shape as Stage 2, but align at latent positions, not observation positions.
  • No latent-only-BP surrogate. Alignment gradient flows through the whole trunk.
  • Teacher = the Stage-2 SFT checkpoint's latent hidden states, precomputed and cached on disk (latent_{all_layers|last_layer}_{ds}_{sid}.pt).
  • Init = Stage 1 ckpt (not Stage 2!).
  • The student's question image is kept; only assistant-turn aux images are dropped.

Stage 3 has a structural risk: it supervises against a latent-of-a-latent with no encoder grounding. If the teacher's latents are themselves uniform, the student inherits the uniformity.

Importance ratio (Eq. 8)

$$r_{i,t}(\theta) = \exp\!\bigg(-\frac{1}{2\sigma^2}\|h^{\text{old}}_{i,t} - h^\theta_{i,t}\|^2\bigg)$$

Treat the old policy's emitted latent as a Gaussian sample from N(hθ, σ²I). Normalizer cancels in the ratio.

Six things to know that the paper doesn't say

1

allow_unused=True silently zeros the proxy if ce_patch_vec isn't in the CE-forward graph. Smoke-gate this.

2

emphasize_latent_weight and alignment_weight are different knobs. The 2.0 × 2.0 default gives effective 4× pressure on the latent-generation graph.

3

ce_emphasize_factor jumps from 2.0 (S1) → 4.0 (S2/S3). Paper doesn't ablate.

4

Stage 3 does NOT use the latent-only-BP surrogate. Paper's emphasis is S2-only.

5

gradient_checkpointing must be toggled around the latent forward — disable for latent (use_cache=True), re-enable for CE. Not optional.

6

batch_size=1 only is tested upstream. Larger bsz untested per in-code warning at modeling_qwen2_5_vl_monet.py:1745.

Where to plug in a controlled variation — the action card

H1

Swap the alignment loss

At alignment_loss(...). VICReg drops the teacher: variance hinge + cov penalty self-supervised. Barlow Twins keeps teacher. InfoNCE needs negatives (awkward at bsz=1).

H2

Swap the latent-only-BP surrogate

At compute_latents_only_loss. Last-N-layer restriction, detached-MSE, grad-clip variants.

H3

Replace the latent input embedding

At modeling:1914-1916. VQ-VAE codebook, random-projection bottleneck, cross-attention pooling. Load-bearing — comparison no longer apples-to-apples.

H4

Replace the 4D mask policy

At build_4d_attn. Toggle ten flags; --not_use_4d = useful baseline.

H5

Per-position regularizer on latents

Add to trainer between latent and CE forwards. Variance hinge + cov penalty on ce_patch_vec[b] — anti-collapse signal. cluster/configs/v3_monet_plus_vicreg.yaml already wired.

H6

Swap teacher choice

Base Qwen vs S1-SFT vs 72B vs EMA-self. Our cluster port uses base Qwen (deviation #3); upstream uses S1-SFT.

H7

Drop Stage 3 entirely

Skip self-distill; keep Stage 2. Phase 0 suggests Stage 3 is the collapse source.

H8

Add a latent-shape reward in RL

Diversity bonus, decoder-utility bonus. Paper uses minimal acc + format only.

V3 config ready (v3_monet_plus_vicreg.yaml). Hypothesis: VICReg helped at 3B/5K (Pivot A); should help at 7B/118K — effect may be smaller given alignment already shapes structure.

Can we replace Stage 3 with a non-self-distill anti-collapse Stage 3?

Q5

What's the right σ for VLPO?

Paper picks 10.0; no ablation. σ trades learning signal sharpness vs gradient stability. Out of scope for SFT-only roadmap but flag for future RL.
